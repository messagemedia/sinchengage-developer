## What Changed

- Publishes two new machine-readable files, `llms.txt` (curated index) and `llms-full.txt` (full inlined documentation), on every docs build, discoverable via `<link rel="alternate">` tags in the site header.
- Added three new standalone guide pages (Basic Authentication, HMAC Authentication, Sub-accounts) that were previously only viewable inline inside the OpenAPI reference, and wired them into the existing "Copy for LLM" page action.
- The docs build now fails if the curated `llms.txt` content falls outside its 1,000–3,000 token budget, a required section is missing, or a curated link points at a file that doesn't exist.

## Why

AI agents and crawlers need a single-fetch, machine-readable index of the API documentation that stays in sync with the canonical docs on every publish, per the MAPI-2251 epic's AI-agent documentation goals.

## Affected Components

- `docs` (curation config and new guide pages)
- `scripts` (llms.txt/llms-full.txt generator)
- `web` (site template, discovery tags, page-action wiring)
- `build-config` (npm script, new dependency)
