## What Changed

- Published a public **AI Integration** guide documenting every agent-readable artifact (`llms.txt`, `llms-full.txt`, per-page Markdown, `openapi.yaml`/`openapi.json`), the `rel="describedby"` / `rel="alternate"` discovery tags, the on-page Copy for LLM / View as Markdown actions, and the versioning conventions.
- Added copy-paste setup instructions for four AI clients — Claude Code, Cursor, ChatGPT, and Perplexity — plus a generic recipe for any agent or script.
- Linked the guide from the docs navigation (an `AI Integration` `kind: nav` tag in the Guides tag group), the guides index, and the curated `llms.txt` index, and repointed the existing "For AI Agents" section of `info.description` at it.
- Registered the guide in the page-actions widget so its section carries the same Copy for LLM / View as Markdown links as every other guide and service.

## Why

Customers and the wider AI ecosystem could not discover how to point their tools at the AI-readable artifacts shipped by MAPI-2256 and MAPI-2555, making adoption of the docs uplift invisible and slower than necessary.

## Verification

- `npm run lint` — passes, including `vocabulary/controlled-terms` on the new spec prose.
- `npm run build` — passes; curated `llms.txt` measures 1,266 tokens against its hard 1,000–3,000 gate, and the guide is inlined in `llms-full.txt` at the stable anchor `docs-guides-ai-integration-md`.
- Every URL printed in the guide returns 200 on `https://developers.app.sinch.com` except the guide's own path, which resolves once this change deploys.
- The widget's tag map resolves `tag/AI-Integration` to `docs/guides/ai-integration.md`, so the new section renders the page actions rather than being skipped.
