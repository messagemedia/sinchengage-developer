## What Changed

- Expanded the **AI Integration** section of the API reference intro to list every agent-readable artifact (`llms.txt`, `llms-full.txt`, per-page Markdown, `openapi.yaml`/`openapi.json`) with its URL and purpose, and to explain the `rel="describedby"` / `rel="alternate"` discovery tags and the `externalDocs` pointer.
- Published a **AI Integration** guide with copy-paste setup for four AI clients — Claude Code, Cursor, ChatGPT, and Perplexity — plus a generic recipe for any agent or script, the on-page Copy for LLM / View as Markdown actions, and the versioning conventions.
- Linked the guide from the intro section, the guides index, and the curated `llms.txt` index, so agents reading only `llms.txt` still find it.
- Gave the AI Integration section the same Copy for LLM / View as Markdown page actions the endpoint and guide sections already have, so the whole guide can be handed to an assistant in one click.

## Why

MAPI-2256 and MAPI-2555 shipped the AI-readable artifacts and their discovery tags, but nothing told customers they exist or how to point a tool at them, leaving the docs uplift invisible to the developers meant to benefit from it.
