## What Changed

- The API now documents a US regional instance at `https://us.app.api.sinch.com` alongside the existing EU and APAC base URLs.
- ReDoc's server list, every existing Markdown Base URLs table, and the generated `llms.txt` Authentication note include the US host.
- Auth and sub-account guides keep EU in examples and note that the `Host` header must match the account region (`eu` / `au` / `us`).

## Why

US is a supported regional instance and the developer docs needed to list it with EU and APAC.
