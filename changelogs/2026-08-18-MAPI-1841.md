## What Changed

- The shared OpenAPI `Status` enum now matches the rest-api `MessageStatus` wire values, including `held`, `processing`, `read`, and `undefined`, and no longer lists `undeliverable`.
- Get message status, send messages, check delivery reports, and detail-report Markdown now list that same enum.

## Why

GetMessageStatus already returned `held` (and other statuses) that the published docs omitted, so customers could not map live responses to the documented contract.

- `spec`
- `messages`
- `delivery-reports`
- `messaging-reports`
