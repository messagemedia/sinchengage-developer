## What Changed

- The Contacts docs now describe the rate limit on the 12 create, update and delete endpoints: 20 requests per second per account and 100 requests per second across all accounts. Read (`GET`) endpoints are not limited.
- Each rate-limited operation documents a `429 Too Many Requests` response with a `Retry-After` header (seconds, at least 1) and an `ApiError` body of type `too_many_requests`.
- The Contacts overview gives retry guidance and lists the rate-limited endpoints. The API index and the curated LLM index describe the same limit.

## Why

The Contacts API now enforces per-account and global rate limits on write requests (CONTACTS-3682 / CONTACTS-3836), and clients need to know the limits and how to handle a 429.
