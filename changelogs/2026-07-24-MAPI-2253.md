## What Changed

- OpenAPI is upgraded to 3.2 with contact metadata, controlled vocabulary, CI hygiene gates, YAML/JSON downloads from Pages, cleaner code samples, and accurate 401/no-429 error contracts across secured operations.
- Public docs navigation and prose are tightened: number-management tags are grouped separately, obsolete Development Tools guidance is removed, Redoc-compatible fences keep highlighting, and distracting typos are corrected without rewriting meaning.
- Production-accurate examples stay as-is while schema mismatches and deferred contract-sensitive follow-ups are tracked in-repo (`backlog.md`).

## Why

Warn-only lint and noisy or incorrect OpenAPI artifacts let documentation regressions merge and block reliable client and agent integrations.
