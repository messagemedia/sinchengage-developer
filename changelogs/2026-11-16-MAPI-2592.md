## What Changed

- Added a Channel selection section with the full T1–T8 truth table, per-row outcome explanations, and an inferred-RCS code example to the Send messages portal page and OpenAPI endpoint description.
- Updated `Format`, `rich_content`, `suggestions`, `fallback_message`, and `content` OpenAPI schema descriptions to state when RCS is inferred, when requests are rejected with 400, and that `fallback_message` never selects a channel and does not satisfy `content`.
- Added a Channel selection section to the `llms-curation.yaml` so the inference rules appear in `llms.txt` for AI tool discoverability.

## Why

Developers had no documented explanation for why a message was (or was not) sent over RCS, requiring them to guess at undocumented inference rules.
