# Credits

Get the credit balance for an account, including remaining MT SMS and MT MMS credits and when they expire.

## Base URLs

| Environment | URL |
|-------------|-----|
| EU instance | `https://eu.app.api.sinch.com` |
| APAC instance | `https://au.app.api.sinch.com` |
| US instance | `https://us.app.api.sinch.com` |

## Choose an endpoint

| Goal | Endpoint |
|------|----------|
| Retrieve the remaining credit balance for the account | [Get Credit Balance](get-credit-balance.md) |

## Endpoints

| Endpoint | Method | Path | Description |
|----------|--------|------|-------------|
| [Get Credit Balance](get-credit-balance.md) | `GET` | `/v1/credits_management/account` | Get the credit balance for a prepaid account |
