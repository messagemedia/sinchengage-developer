# Guides

Cross-cutting guides that apply across the Sinch Engage API, rather than to a single endpoint.

| Guide | Description |
|-------|-------------|
| [Basic Authentication](basic-authentication.md) | Authenticate requests with a Base64-encoded API key/secret. |
| [HMAC Authentication](hmac-authentication.md) | Authenticate requests by signing them with an HMAC-SHA256 signature. |
| [Sub-accounts](sub-accounts.md) | Perform actions on behalf of a sub-account using a parent account's API key. |
